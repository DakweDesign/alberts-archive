# Albert's Archive — site files

A digital archive of Albert's (@pen.ultimate.inks) fountain pen collection.
Plain HTML + CSS + vanilla JS (Lenis for smooth scrolling; no build step).

- `index.html` — the page (hero, intro + search, Montblanc / Nakaya / Tohma banners and card stacks)
- `css/style.css` — all styles
- `js/main.js` — scroll animations, galleries, search, menu, cursor
- `js/vendor/lenis.min.js` — smooth scroll library
- `img/` — hero, brand logos, card images (`work-N.jpg`) and gallery squares (`g*-N.jpg`)

To view: open `index.html` in a browser, or serve the folder with any static server.
To publish: upload the whole folder as-is to any static host (Netlify, Vercel, GitHub Pages, etc.).
